Roblox Audio Auto-Mastering — v15 Python · NumPy/SciPy · FFmpeg · Signal Processing

Automatic audio mastering engine for Roblox, where games don't apply their own loudness normalization — so LUFS targeting hits the player experience directly. A 4-pass pipeline (identity analysis, temporal mapping, adaptive processing, verification) masters each track toward the best version of itself rather than a generic loudness standard, with a coherence score and batch consistency report verifying the output. The same rubric-driven, evidence-based verification discipline as the QC work, applied to DSP instead of data.
